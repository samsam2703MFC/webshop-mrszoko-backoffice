If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.

If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

## Quick map
- `readme.md` — the full brand guide: voice, visual foundations, iconography, index.
- `styles.css` — link this one file to get all tokens + fonts (`tokens/*.css`).
- `assets/logo.png` — the one true brand mark (deep-chocolate pebble + profile).
- `components/` — React primitives (core, forms, commerce, layout).
- `templates/webshop/`, `templates/couverture-shop/` — interactive storefront + B2B webshop templates to copy patterns from.
- `guidelines/` — foundation specimen cards (type, colour, spacing, brand).

## Essentials
- Primary colour: deep cocoa `#41281A` (`--choco-700`); page bg warm cream `#FBF6EF`.
- Type: DM Serif Display (headlines), Mulish (UI/body), DM Mono (prices/labels).
- Pill buttons, soft corners, warm brown-tinted shadows, gentle "melt" motion.
- No emoji. Sentence case; uppercase mono eyebrows with wide tracking.
- Fonts and all imagery are placeholders/substitutes — see readme caveats.
